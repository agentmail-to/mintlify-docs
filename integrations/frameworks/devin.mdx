Devin, Cognition's hosted software engineering agent, connects to AgentMail through its MCP Marketplace. One custom MCP entry gives every Devin session `@agentmail.to` inboxes to list, create, and send from, driven by plain instructions.

## 0. Before you start

You need two things:

- A Devin account where you hold the **Manage MCP Servers** admin permission. Without it, use **Suggest MCP Integration** to ask an admin to add the server.
- An AgentMail API key. Generate one in the [AgentMail Console](https://console.agentmail.to/dashboard/api-keys) and keep it at hand: you will paste it into Devin's form.

## 1. Add the AgentMail MCP server

In Devin, open **Settings > Connections**, switch to the **MCP servers** tab, and click **Add a custom MCP**. Fill the form:

| Field | Value |
| --- | --- |
| Server name | `AgentMail` |
| Short description | `Email inboxes the agent can create, send from, and reply from.` |
| Transport type | `HTTP` |
| Server URL | `https://mcp.agentmail.to/mcp` |
| Authentication | `Authorization header`, with header key `x-api-key` and your API key as the value |

<Frame caption="The AgentMail entry filled in: HTTP transport, the hosted server URL, and the x-api-key authorization header.">
  <img src="/images/integrations/devin-add-custom-mcp.png" alt="Devin's Add a custom MCP form filled in for AgentMail" />
</Frame>

The form's **Import JSON** button accepts the equivalent JSON:

```json
{
  "transport": "HTTP",
  "url": "https://mcp.agentmail.to/mcp",
  "auth_method": "auth_header",
  "headers": { "x-api-key": "<API_KEY>" }
}
```

AgentMail's server also supports OAuth: choose `OAuth` as the authentication method instead and Devin walks you through the flow. [MCP and Skills](/integrations/mcp-and-skills) covers both options and the full tool catalog.

Click **Install and enable** and confirm the security notice. On the server's page, click **Test tools**: Devin validates the connection in an isolated environment and lists the AgentMail tools on success, with **Enable in sessions** switched on.

<Frame caption="A successful validation: the AgentMail tools discovered and enabled for sessions.">
  <img src="/images/integrations/devin-test-tools.png" alt="Devin reporting MCP server validation successful with the AgentMail tool list" />
</Frame>

<Accordion title="Troubleshooting">

- **Test tools fails.** The Server URL must be exactly `https://mcp.agentmail.to/mcp`, and the header key must be `x-api-key`. A `401` means the key value is missing or invalid.
- **There is no "Add a custom MCP" button.** Your account lacks the **Manage MCP Servers** permission. Use **Suggest MCP Integration**, or ask an organization admin.

</Accordion>

## 2. Test sending emails

Start a new Devin session and give it the job in plain language. Put your everyday address in place of `you@example.com`:

```text
Create an AgentMail inbox with the display name "Support agent" and send an
email from it to you@example.com with the subject "Hello from Devin".
Report the inbox address back to me.
```

The email reaches that account within moments. Devin makes two tool calls, `create_inbox` and then `send_message`, and reports the new address back. Save the address: you will email it in the next step.

<Accordion title="Troubleshooting">

- **`403` when your prompt asks for a taken username.** The error lists up to three available variants in `suggestions`, and it reaches Devin as a tool result, so it can pick one and retry. Asking for an inbox without naming a username always works.
- **`403` `limit_exceeded` at your plan's inbox cap.** The create returns this instead, before any name check.

</Accordion>

## 3. Test receiving and replying

From your own account, reply to the email, then tell the session:

```text
Check the inbox you created for new mail and reply to the latest message
with a short acknowledgment.
```

Devin lists the inbox's threads, reads your reply, and answers in the same thread with `reply_to_message`. The reply lands in your mailbox, threaded under your message.

Delivery takes about two seconds in each direction, so a session that reports an empty inbox has probably checked before your email arrived. Ask it to check again.

# Connect Devin to AgentMail

Add AgentMail's hosted MCP server as a custom MCP in Devin's marketplace and every Devin session gets `@agentmail.to` inboxes to list, create, and send from. Auth is an AgentMail API key sent as a request header.

## Do this

1. Generate an API key at `https://console.agentmail.to/dashboard/api-keys`.

2. In Devin, open **Settings > Connections**, switch to the **MCP servers** tab, click **Add a custom MCP**, and configure:

```json
{
  "transport": "HTTP",
  "url": "https://mcp.agentmail.to/mcp",
  "auth_method": "auth_header",
  "headers": { "x-api-key": "<API_KEY>" }
}
```

3. Click **Install and enable**, confirm the security notice, then click **Test tools** on the server page. On success the AgentMail tools are listed, **Enable in sessions** is on, and every session can invoke them by natural-language instruction.

## Facts

- Adding a custom MCP server requires Devin's **Manage MCP Servers** admin permission. Non-admins request one with **Suggest MCP Integration**.
- The AgentMail server URL is `https://mcp.agentmail.to/mcp`, transport `HTTP`, authentication `Authorization header` with key `x-api-key`.
- The server also supports OAuth. Devin's OAuth callback URL is `https://api.devin.ai/mcp/oauth/callback`.
- **Test tools** validates the connection in an isolated environment before any session uses it. Success reads "MCP server validation successful" with the tool list alongside.
- Full tool catalog, OAuth details, and configs for other MCP clients: `/integrations/mcp-and-skills`.

## Errors

| Error | Cause | Fix |
| --- | --- | --- |
| Test tools fails, `401` | Wrong Server URL, or the `x-api-key` header value is missing or invalid | Set the URL to exactly `https://mcp.agentmail.to/mcp` and paste a valid API key |
| `403` `resource_taken` or `already_exists` on `create_inbox` | The requested username is taken | Retry with one of the up to 3 names in `suggestions`, or omit `username` |
| `403` `limit_exceeded` on `create_inbox` | The plan's inbox cap is reached; this fires before the name check | Delete an inbox or raise the cap as the error's `fix` directs |

## Verify

**Test tools** succeeds, and a session instructed to create an inbox and send an email reports back the new `@agentmail.to` address with the message delivered.
